# E-Commerce Website

A simple 3-tier e-commerce application with React frontend, Node.js backend, and SQLite database.

## Setup

1. Install backend dependencies:
```bash
cd backend
npm install
```

2. Install frontend dependencies:
```bash
cd frontend
npm install
```

## Running the Application

1. Start the backend server:
```bash
cd backend
npm start
```
Server runs on http://localhost:3001

2. Start the frontend (in a new terminal):
```bash
cd frontend
npm start
```
Frontend runs on http://localhost:3000

## Features

- Home page with 20 products (emoji images)
- Product detail page with description, price, reviews, and add-to-cart
- Shopping cart with quantity updates and item removal
- SQLite database for products, reviews, and cart items
